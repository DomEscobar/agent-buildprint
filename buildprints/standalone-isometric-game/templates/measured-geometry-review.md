# Measured geometry review — packet report version 1

Supporting review artifact, not an upstream executable schema. Required for `assembly-measured-geometry`; optional elsewhere unless the approved contract requires it. Use existing requirement coverage and review artifacts, not extra art-contract v1 fields. Empty or ambiguous observations are unverified, never default pass.

- Requirement/view and candidate/baseline; reviewer, date and independent/self/unavailable:
- Reference identity/role/rights, asset/source/native/playing capture SHA-256 values:
- Source crop and ordered transform chain; annotated overlays are derivatives, link unedited captures:
- Actual loaded host projection convention/export hash, anchor, footprint, source-to-world scale and runtime binding/source/build hashes:
- Semantic endpoint IDs and corresponding coordinates on source/native/playing images; classify EACH point observed / inferred / authored, uncertainty in pixels and concealed endpoints:
- Expected structural axis from host definitions or deliberate non-axis geometry, independently of raster landmark selection:
- Edge rise/angular residuals with uncertainty and agreed tolerance; contact polygon and long-axis compatibility, separate solid/top clearance:
- Bounded pass/fail/unverified findings; artifact links, unresolved observations and upstream/host capability gaps:

Select raster endpoints before comparison; do not inverse-fit the model to those same points, use decorative grain or bounding-box ratio as an axis, require hidden feet to become observed, or infer an error solely from tabletop overhang. Agree stylized proportions/landmarks, not invented meters. A geometrically valid shell or asymmetric furnishing layout is not a failure.

## Authored negative calibration facts (not game evidence)
For a 53.2 native-pixel structural run whose independently exported expected rise is 26.6 px, shallow rail rises of 7–10 px leave residuals of −19.6 to −16.6 px; a 26.1–27.1 px rise passes only an agreed ±1 px rise claim. These minimal synthetic facts contain no source artwork and do not establish a universal c/r convention, actual captures, anatomy or automatic raster verification.
