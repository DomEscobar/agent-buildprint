# Frozen review and honest delivery

## How to implement this loop
Read `loops/loop-flow.md`, `.buildprint/next-agent.md`, host `AGENTS.md`, `02-identity.md`, the agreement and current proof. Missing runtime context is a blocker, not permission to guess. Work on the smallest real path and inspect it before expanding.

## Building objective
Read `review.md`, `references/qa.md` and `templates/milestone-evidence.md`. Freeze code revision, build digest and hashes of every loaded manifest and asset before independent review. Give a fresh-context reviewer only the goal, active loop contracts, identity, diff and proof, not builder conversation. Reproduce the play path against that exact build and record failures by contract; fixes invalidate affected evidence and need focused regression plus the final full slice milestone, not repeated broad campaigns after every minor edit. For public deployment, verify HTTP response and MIME, referenced asset URLs and bytes, browser interactions and errors independently; online multiplayer additionally needs authenticated WSS where applicable, two real clients, state synchronization and reconnect proof. A successful HTML response is not a game release. Keep deployment optional for local scope. Provide working commands, controls, license notices, immutable version, known limitations and a tested restore path to the previous build/assets/save format; do not claim rollback of irreversible save migration without a tested backup.

## DO NOT
Do not pass placeholders as finished art, ship functionless buttons, count mocked/sample data as live proof, or substitute a proof-only runtime for production. Do not expand scope, spend, upload references or change asset rights without agreement. Do not advance on a page-loaded screenshot.

## Minimum proof before moving on
Independent contract verdict bound to the frozen build, full final slice evidence, applicable HTTP/assets/browser/WSS checks and rollback rehearsal. If review, devices or hosting cannot be tested, state exact blocker and lower claim in HANDOVER; never label self-review independent.

## Handoff note
Record changed runtime/manifest paths, decisions, commands and observed results, evidence version, remaining blockers, active loop and next smallest repair. State loop_core_passed separately from claim_qualified; use `review.md` before claiming qualification.
