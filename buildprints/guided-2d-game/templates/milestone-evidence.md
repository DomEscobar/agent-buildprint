# Frozen milestone evidence

- Scope/claim: agreement revision, active loop, included devices and exclusions.
- Version: commit, build SHA-256, loader-reported manifest SHA-256 and each loaded asset hash. Bind screenshots/recordings to this version.
- Commands: exact command, environment/version, result/exit code, relevant test count and observation. Redact private paths/values before publishing.
- Runtime: target URL or local entry command, browser/device, viewport/orientation, input path, observed objective/failure/restart and frame-rate measurements.
- Visual: native-scale contact sheet, motion recording, light/dark alpha review, repeated tiles, clean scene captures and feet/footprint/collision/sorting overlays after movement from multiple directions/camera positions.
- Asset-Maker: dated access evidence for both essential WaveSpeed models and the chosen companion, paid-use approval references, or disclosed quality limitation and free-only fallback/license decision; last-resort SVG justification if used, no equivalent-quality claim, and the same visual QA results.
- Deployment: HTTP status/MIME, assets/bytes, browser play, WSS/two-client checks separately; mark not applicable with reason, not assumed pass.
- Reviewer independence: separate reviewer/session, supplied inputs, inspected version and verdict; no builder chat. REVIEW_INVALID if same implementer.
- Regressions: changed contracts and tests rerun; reason unaffected prior evidence remains valid. Full slice at milestones, not every edit.
- Limits: missing devices/services/visual checks, rights or spend uncertainties and blockers. No page-loaded=done claim.
- Rollback: previous immutable build and matching assets/manifests, backup/save compatibility, actual rehearsal result.
- Handover: controls, commands, licenses, current claim, blockers and next smallest action.
